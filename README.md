# Data Structures and Algorithms in Python

A collection of foundational computer science algorithms and custom data structures implemented in Python. This repository covers classical sorting algorithms, dynamic programming solutions, graph traversal techniques, and object-oriented data structures.

## Repository Overview

### 1. Sorting Algorithms
* **Insertion Sort:** $O(n^2)$ in-place comparison sort.
* **Randomized Quick Sort:** Divide-and-conquer algorithm using randomized pivot selection to ensure average-case $O(n \log n)$ time complexity.
* **Merge Sort & Heap Sort:** Efficient $O(n \log n)$ sorting implementations.

### 2. Dynamic Programming
* **Coin Change I & II:** Multi-combination counting via 2D dynamic programming matrices.
* **Knapsack Problem (0/1):** Optimal resource allocation under capacity constraints.
* **House Robber I & II:** Linear and circular dynamic programming optimization.

### 3. Graph Theory & Search Algorithms
* **Object-Oriented Graph Representation:** Implementations of `Node`, `Edge`, `Digraph`, and `Graph` classes.
* **Depth-First Search (DFS) & Breadth-First Search (BFS):** Traversal techniques, shortest path discovery, and connected component analysis.

### 4. Custom Data Structures & Problem Solving
* **Singly Linked List:** Node-based data structure with insert, delete, and search operations.
* **Interval Scheduling:** Greedy algorithm for non-overlapping interval selection and weighted scheduling using binary search + DP.
* **String Isomorphism:** Character mapping validation using hash maps and sets.

## Environment
* **Language:** Python 3.x
* Standard Library only (no third-party dependencies required).
